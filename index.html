The ten instructions

Every other byte value is data and does nothing when executed. Zero matters because [ and ] test for it.

One epoch

  1. Each byte in the soup has a 1 in 4,096 chance of being replaced with a random byte (at the paper's rate).
  2. Programs are paired at random (or with a nearby neighbour on the 2D grid). Each pair is joined into a 128-byte tape, A then B.
  3. The tape runs from byte 0 for up to 8,192 steps, with both heads starting at 0. Code and data share the tape, so a program can rewrite itself and its partner.
  4. The tape is cut back into two 64-byte programs and returned to the soup.

Watch for the moment the instruction count jumps and the high-order entropy rises: copies are now outcompeting noise. The timing is random. In the paper, about 40% of runs with 131,072 programs got there within 16,000 epochs; smaller soups and unlucky seeds can take much longer, so try a few seeds.

Based on Agüera y Arcas et al., Computational Life (2024). The interpreter follows the bff_noheads variant in Google's cubff. Entropy here uses deflate rather than brotli, so values differ a little from the paper's.
